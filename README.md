# Requisitos do Sistema

## Requisitos Funcionais (RF)
- **RF01:** Cadastro de advogados com validação da advogados do Brasil.
- **RF02:** Cadastro simples de clientes.
- **RF03:** Busca de advogados por área e localização.
- **RF04:** Envio de solicitação de contato entre cliente e advogado.
- **RF05:** Vinculação de processos ao cliente.
- **RF06:** Tradução automática de termos jurídicos para linguagem simples.
- **RF07:** Visualização do andamento do processo em linha do tempo.
- **RF08:** Envio e compartilhamento de documentos.
- **RF09:** Notificações sobre novas movimentações do processo.

---

## Requisitos Não Funcionais (RNF)
- **RNF01:** Conformidade com o Provimento 205/2021 da OAB.
- **RNF02:** Exibição de aviso informando que a tradução é apenas educativa.
- **RNF03:** Criptografia de senhas e documentos.
- **RNF04:** Não consultar automaticamente processos em Segredo de Justiça.
- **RNF05:** Interface responsiva para computador e celular.
- **RNF06:** Interface acessível, com linguagem simples, boa legibilidade e contraste.
